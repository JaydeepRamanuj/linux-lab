Critical Incident Quick-Path • Scenario #01: "I accidentally committed straight to main"
Safe / Non-destructive
Repository Topology HEAD pointing to main
info Keep your uncommitted changes intact without altering remote history.
recovery-workflow.sh
01
$ git branch feature/my-cool-feature

Captures the current commit on a brand-new branch pointer.

02
$ git reset --soft HEAD~1

Rolls main back 1 commit while leaving your file changes staged in memory.

03
$ git checkout feature/my-cool-feature

Switches to your new branch where your staged work is cleanly preserved.
